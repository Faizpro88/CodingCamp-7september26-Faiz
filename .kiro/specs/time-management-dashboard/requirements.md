# Requirements Document

## Introduction

The application helps users manage their time effectively through a dashboard with greeting, focus timer, todo list, and quick links.

## Glossary

- **Dashboard**: The main page showing all widgets

- **Greeting_Module**: Displays greeting based on time of day

- **Focus_Timer**: The 25-minute countdown timer based on Pomodoro

- **Todo_List**: List to manage user tasks

- **Task**: A user-defined item with title and completion status

- **Quick_Links**: Collection of favorite website links

- **Quick_Link**: A single website with name and URL

- **Local_Storage**: Browser's Local Storage API for saving data

- **Time_Of_Day**: morning 05:00-11:59, afternoon 12:00-17:59, evening 18:00-21:59, night 22:00-04:59
